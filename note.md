# Portfolio Project Notes & Deployment Cheat Sheet

## 🚀 Quick Deployment & Git Workflow

Whenever you make changes to your portfolio and want to update your live website on Vercel:

```bash
# 1. Stage all your changes
git add .

# 2. Commit your changes with a descriptive message
git commit -m "Update portfolio projects and content"

# 3. Push to GitHub (Vercel automatically redeploys your site in 20 seconds!)
git push
```

---

## 🛠️ Local Development Commands

Run these commands from the root directory of your portfolio:

| Command | Description |
| :--- | :--- |
| `npm run dev` | Starts local Vite development server with hot-reload |
| `npm run build` | Bundles static production assets into `dist/` |
| `npx tsc --noEmit` | Performs TypeScript typecheck without generating output |
| `npm run preview` | Previews the production build locally |
